# Звук игры

В `music/` лежат три бесшовных зацикленных Ogg Vorbis-трека: `menu.ogg`, `run.ogg` и `boss.ogg`. Музыкой и переходами между треками управляет `audio_manager.gd`.

В `sfx/` лежат короткие Ogg Vorbis-эффекты. Для каждого заклинания создан отдельный файл `spell_<id>.ogg`; имена `<id>` совпадают с идентификаторами из `spell_catalog.gd`. Остальные файлы покрывают выстрелы мага, атаки врагов и босса, награды, переходы, мантии, смерть и завершение забега.

Все исходные аудиофайлы созданы процедурно для этой сборки. Общую громкость регулирует существующий ползунок настроек игры; относительные уровни и ограничение частоты повторов настраиваются в `audio_manager.gd`.
